# Base local de municípios

Snapshot dos municípios brasileiros usado para manter o seletor disponível quando a API externa do IBGE estiver indisponível.

Fonte: [kelvins/municipios-brasileiros](https://github.com/kelvins/municipios-brasileiros), licença MIT. A base contém código IBGE, nome, UF e coordenadas centrais. A validação dos limites municipais continua usando a API de Malhas do IBGE quando disponível.
